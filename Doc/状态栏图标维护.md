## 换图案

编辑 JSON 的 `bitmaps`：每个条目包含 `name` 和等宽的 `rows` 字符串数组。宽高从点阵自动推导，资源字节数由 `sizeof` 生成。

- `#`：白色亮点，编码为 1。
- `.`：不绘制，编码为 0；状态栏每帧先清黑，所以显示为黑色。
- 注意：主菜单素材工具的 `#` 是白底上的黑色字形，两类素材的极性不同。必须使用 `--status`。
- 当前状态栏高 20px，最后一行为分隔线，图标高度最多 19px；实际建议 10～14px。
- 小图使用原生尺寸，不缩放。想换大小时直接修改点阵宽高，布局自动计算。

从工程根目录执行：

```powershell
python Tools/icon_gen.py --status --write --preview
python Tools/icon_gen.py --status
```

生成 `Tools/status_icons_preview.png`，编译时只依赖生成好的头文件，不需要 Python/Pillow。校验与生成仅需 Python 标准库，预览需要 Pillow。

## 新增、删除、换序

在 JSON 的 `layout` 中配置条目：

```json
{"id": "wifi", "bitmap": "wifi", "visible": true}
```

- 新增：增加一个点阵，向 `layout` 增加条目，再运行生成命令，无需改 HAL 或生成器符号映射。
- 删除：从 `layout` 删除条目；不用的点阵也可以删除。仅删除点阵但保留引用会被工具拒绝。
- 隐藏：将 `visible` 设为 `false`，或在运行中调用显隐接口。
- 排序：数组从右向左绘制，前面的条目优先显示。当前顺序为 battery、wifi、tf。
- 多条目可以共用同一份点阵。稳定的 `id` 用于应用接口，素材名用于选用图案，两者可以不同。
- 空列表合法，标题可使用整个宽度。

图标间距为 2px，至少给左侧标题预留 32px。图标过宽、过高、数据无效或空间不足时跳过，不写入内容区或底部分隔线。后面较小的条目仍可以使用剩余空间。标题根据实际绘制后的边界截断。

## 日后接入真实状态

在 C++ 应用代码中包含 `Astra/astra/status_bar.h`，从主循环/UI 上下文调用：

```cpp
astra::statusBarSetVisible("wifi", false);  // 隐藏，下次刷新自动重新排列
astra::statusBarSetVisible("wifi", true);
astra::statusBarResetIcon("wifi");         // 恢复这一项的默认图和默认显隐
astra::statusBarResetIcons();              // 恢复全部默认状态
```

图案切换使用共用 Bitmap，例如电池空电状态：

```cpp
static const uint8_t emptyBatteryData[] = {
    0x00,0x00, 0xFC,0xFF, 0x06,0x80, 0x06,0x80, 0x06,0x80,
    0x06,0x80, 0x06,0x80, 0x06,0x80, 0xFC,0xFF, 0x00,0x00
};
static const astra::Bitmap emptyBattery = {
    emptyBatteryData, 16, 10, sizeof(emptyBatteryData)
};
bool ok = astra::statusBarSetBitmap("battery", &emptyBattery);
```

接口不复制点阵：Bitmap 对象和数据都必须长期有效，建议 `static const`。不能传入函数栈上的局部资源。切换图案不改变显隐；无效 ID、空指针、零尺寸或长度不足会返回 `false` 并保持原资源。接口不在中断中使用；真实外设状态应先传递到主循环。当前模块不自行采样电池或操作 Wi-Fi/TF 硬件。
